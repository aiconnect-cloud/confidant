# Contributing

Thanks for your interest in contributing to Confidant.

## Quick start

- Install: `npm install`
- Test: `npm test`
- Build: `npm run build`

## How to contribute

- **Bug reports**: include steps to reproduce, expected vs actual behavior, and your environment (Node version, OS).
- **Security issues**: please do **not** open a public issue. See `SECURITY.md`.
- **Pull requests**:
  - Keep PRs focused and small when possible.
  - Include tests for behavior changes.
  - Run `npm test` and `npm run build` before requesting review.

## Project principles

- Don’t log secrets.
- Prefer clear, boring code over cleverness.
- Backwards-compatibility matters for the CLI.

## Development notes

- Node.js: `>=18`
- TypeScript: strict mode
