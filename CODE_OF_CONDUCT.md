# Code of Conduct

This project is committed to providing a friendly, safe, and welcoming environment for everyone.

## We expect

- Be respectful and constructive.
- Assume good intent and communicate clearly.
- Keep discussions focused on improving the project.
- Respect privacy and security boundaries (especially because this project handles secrets).

## We do not tolerate

- Harassment, discrimination, or abusive behavior.
- Sharing private information without consent.
- Encouraging unsafe handling of credentials or secrets.

## Reporting

If you experience or witness unacceptable behavior, please contact the maintainers. If the report is security-related, follow the process in `SECURITY.md`.

## Enforcement

Maintainers may remove, edit, or reject contributions and communications that violate this Code of Conduct.
